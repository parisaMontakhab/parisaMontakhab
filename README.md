A full-stack web application for discovering and booking tours.

I used this project to practice building and connecting the frontend, backend, database, authentication and payment layers of a real web application.

### Key Features

- 🔐 User signup, login and logout
- 🔑 JWT authentication
- 🛡️ Authorization and role-based access control
- 👤 User account management
- 🔒 Password reset and password update
- 🏔️ Tour management
- ⭐ Reviews and ratings
- 💳 Stripe payment integration
- 📅 Tour booking system
- 🖼️ Image upload and processing
- 🗺️ Geospatial queries
- 🔎 Filtering, sorting and pagination
- 🔌 RESTful API
- 🧪 API testing with Postman
- 🚀 Production deployment

### Built With
