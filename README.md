# 💫 About Me

👋 Hi, I’m **Parisa Montakhabisani**, a **Junior Full-Stack Developer** based in Rome, Italy, with a background in Software Engineering.

💻 I build responsive, maintainable, and user-friendly web applications, with a strong focus on **React, Next.js, TypeScript, and modern frontend development**.

⚙️ On the backend, I work with **Node.js, Express.js, MongoDB, and Mongoose** to build RESTful APIs and full-stack applications.

🚀 Through my projects, I’ve gained hands-on experience with:

* RESTful API design and development
* Authentication & authorization with JWT
* Role-based access control
* MongoDB & Mongoose
* Stripe payment integration
* Booking and review systems
* Image upload and processing
* Geospatial queries
* Error handling and API security
* Deployment of full-stack applications
* Git & GitHub workflows

🎨 On the frontend, I enjoy creating reusable components, responsive interfaces, integrating APIs, and turning designs into functional web applications.

🌱 I’m currently focused on strengthening my **Full-Stack JavaScript development skills** and building production-style projects that solve real-world problems.

💬 **Ask me about:**
React, Next.js, TypeScript, JavaScript, Node.js, Express.js, MongoDB, REST APIs, responsive design, and full-stack development.

⚡ **Fun fact:**
I enjoy solving coding problems, debugging challenging issues, and learning by building real projects.
